# Цеттель

Архив мыслей. Статический сайт на GitHub Pages.

## Структура

- `index.html` — разметка и подключение шрифтов/скриптов
- `style.css` — стили, адаптивность, анимации
- `app.js` — логика: роутинг, рендер, поиск, навигация, лайтбокс
- `data.js` — массив заметок `notes`

## Запуск

Откройте `index.html` в браузере или разверните на GitHub Pages.
